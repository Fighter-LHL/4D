# Play Mode Smoke Test — v0.4.0 庭院试玩与旧五关回归

当前有六个可玩关卡、七个启用场景（含 LevelSelect）。主体验为 **LevelSelect → 回响庭院 → 返回首页**；旧五关保留 **Garden → Platform → Gate → Chambers → Hazard** 回归链。

以下是待执行的验收步骤，不是通过记录。Editor 人工冒烟、macOS 独立应用冒烟及自动化结果分别记录。尚未附本次证据的项目保持未确认；**五位陌生玩家试玩仍为 0/5**。

## 准备与记录

1. 使用项目指定的 Unity **6000.0.77f1** 打开 `WSliceProto/`；记录代码版本、工作区修改、Unity 版本与运行时间。
2. 从仓库根目录运行 `./scripts/validate-local.sh`，保存本次 L0/L1 receipt 和日志。独立 Validate 单关的退出码不能代替统一校验；验证期间不重新 Generate 场景。
3. 确认七个启用场景：`LevelSelect`、`GardenGraybox`、`PlatformGraybox`、`GateGraybox`、`ChambersGraybox`、`HazardGraybox`、`CourtyardSlice`。`LevelSelect` 为第一项，`SampleScene` 不启用。Build Settings 顺序不等于试玩顺序。
4. 打开 `Assets/_Project/Level/Scenes/LevelSelect.unity`；先在 Game View 选择 1280×720，后续再复测其他尺寸。
5. 每项填写实际结果，并保留截图/录像或日志路径。失败项记录操作、出现位置及恢复方式；未执行项标记“未执行”，不推定通过。

## Part 0 — 首页与入口

1. 进入 Play Mode，确认标题 **W-Slice Demo**、版本 **v0.4.0 — development**、副标题“观察空间，切换切片，让机关留下回响。”与退出按钮可见。
2. 突出的“开始：回响庭院”按钮仅出现一次；下方“机制练习”区域保留五个原关卡按钮，以三列两行排列。原关卡中文名和英文机制说明均可读。
3. 点击突出按钮应进入 `CourtyardSlice`；不能误入旧 Garden 关。另行验证五个练习按钮仍能加载对应关卡。

## Part 1 — 回响庭院：完整解谜

1. 初始状态下角色位于院外、入口关闭、机关未启动、桥未连通。正常界面只提供中文动作指引与“切换切片”“提示”，不出现内部节点名、W 数值答案或调试路线。
2. 先点击关闭的入口或不连通的目标，确认角色没有穿墙或凭空越过缺口，并能看到可理解的中文反馈。
3. 拖动滑条观察入口，待门洞与通路显现后，点击庭院落脚点。仅拖动、等待或点击无效目标不能跳过首段教学；角色实际到达庭院后，教学才推进。
4. 在庭院安全位置换切片，找到通往机关的斜坡。此时尝试在远处点击机关，不应激活。先点击上方平台或机关前落脚点，确认角色沿有支撑的坡面抵达机关旁。
5. 到达后点击场景机关或“启动机关”按钮，确认机关转动、出口锚点发生可见变化，教学提示返回庭院。站在机关旁换到其他切片仍应可以启动；无需固定某个 W 值。
6. 保持或恢复斜坡显现的切片，返回庭院。换切片时观察机关与出口锚点，已完成的操作必须保留，教学应在实际返回后推进到寻找出口。
7. 找到出口桥面连通的切片，点击出口侧落脚点并走到出口。桥面必须在角色脚下提供连续支撑，不能穿过看似封闭的结构或在空中行走。
8. 只有已启动机关且抵达出口才能通关。确认中文通关面板出现，“再试一次”“关卡选择”可用；庭院作为独立试玩不显示下一关，按 **N** 也不进入旧关。

工程复测对照（不要提供给陌生玩家）：入口 W 0.20–0.40，斜坡 W 0.70–0.90，出口桥 W 0.45–0.60 且需机关已启动。可分别用 0.30、0.80、0.525 复现路线；玩家验收依赖可见空间与中文提示。

## Part 2 — 门禁、重复机关与误调恢复

### 未启动不能绕过，重复操作不改变结果

1. 重开并进入庭院，不启动机关。扫描整个滑条范围，再尝试走到出口；出口桥始终不可通行，不能完成关卡。
2. 按完整路线抵达并启动机关，连续点击场景机关数次。机关保持已启动，不反复切换开关，不重复产生结构，也不出现错误。
3. 切换数次切片、离开机关再返回；机关仍保持已启动。正常路径可继续完成，不要求重新激活。

### 移动中故意调走切片

分别重现下表；要在角色仍处于所列路段中途时操作，已到终点后调节不算此项。

| 移动位置 | 故意操作 | 预期恢复位置 |
|---|---|---|
| 院外走向庭院的入口通路 | 入口打开后出发，中途调到入口关闭的切片 | 院外的出发落脚点 |
| 由庭院侧爬上斜坡 | 上坡中途让斜坡隐去 | 坡脚落脚点 |
| 由机关侧平台沿斜坡返回 | 下坡中途让斜坡隐去 | 坡顶安全平台 |
| 机关已启动后跨出口桥 | 过桥中途调到桥不连通的切片 | 本次过桥出发侧的落脚点 |

每项同时确认：角色停止并回到当前路段的出发节点、有可见地面支撑，保持 Playing；出现“这条路隐去了，已回到安全落脚点。可以继续调整切片。”等恢复提示；不出现 Failed 面板。把切片调回后，重新点击目标即可继续，无需 **R**，已启动机关的状态也不能丢失。

另在庭院、坡脚、坡顶、机关旁、桥两端的永久平台站定后扫过滑条全程，确认角色不会悬空或被未发生的移动强行复位。

## Part 3 — 教学、提示、重开与中文界面

1. 从未索取提示的状态开始：等待、无效点击与调整切片都不自动显示三级答案。点击“提示”后逐次显示更明确的帮助，最多三级；点击 UI 按钮不得同时使角色向场景目标行走。
2. 实际完成“进入庭院、抵达机关、启动机关、回到庭院、抵达出口”时核对指引变化。阶段改变后此前展开的提示清空，可重新按需索取。
3. 在尚未激活、已激活但未通关两种 Playing 状态分别按 **R**。角色回院外、切片回初始位置、机关复原、桥重新锁定、首段教学恢复、提示级数归零；任何上一轮恢复提示或通关面板均不能残留。
4. 通关后点击“再试一次”，完成第二轮解谜；确认通关面板第二次仍能出现且按钮可点。随后点击“关卡选择”回到首页，再从突出入口进入庭院，确认是初始状态。
5. 在 **1280×720、1920×1080、1440×900** 分别检查首页、最长提示、机关按钮和通关面板；记录实际窗口/渲染尺寸。顶部文字不遮挡关键路径，底部滑条、提示与机关按钮不重叠，不裁切出屏幕。
6. 检查所有新体验中的中文和标点可辨认、无方块或缺字；菜单旧关卡的中英文说明不溢出。拖动滑条两端及点击每个按钮均有响应；Retina 显示时也检查清晰度与点击位置。

## Part 4 — 旧五关回归

从首页分别加载旧关，并按下列顺序验证下一关链；旧关仍可显示英文教学或调试信息，不把它们误认为庭院的正常界面。

| 关卡 | 必查内容 | 通关后的流转 |
|---|---|---|
| Garden | 调切片穿过缺口，沿连续斜坡到终点平台；开放区间含边界均有脚下支撑，上坡误切片返回坡脚；Playing 时 **R** 重开 | **N** → Platform |
| Platform | 平台对齐时才能从 West 到 East，移开切片不能凭空通过 | **N** → Gate |
| Gate | 合适切片下拉杆解锁；移动中关闭通路应 Failed；**R** 复原机关与角色 | **N** → Chambers |
| Chambers | 依次在低、中、高切片通过三段路径；可见开口与实际通行一致 | **N** → Hazard |
| Hazard | W 约 0.55 时平台可通行；横穿中调低 W 应 Failed，角色回 West，**R** 可重开 | 无下一关 |

每关确认首次通关、重开后再次通关都能显示 OutcomeOverlay，隐藏时不拦截场景点击。Gate / Hazard 的 Failed 规则保留，不能套用庭院的无失败恢复规则。

## Part 5 — macOS 独立应用冒烟

从仓库根目录运行：

```bash
./scripts/build-macos.sh
```

1. 脚本默认创建 `WSliceProto/builds/macos/run-<UTC 时间>-<随机后缀>/W-Slice.app`，拒绝覆盖旧产物和证据。记录控制台 `VERIFIED BUILD ARTIFACT ONLY:` 后打印的本次完整路径，用 `open` 命令打开该路径；不要启动旧的固定位置产物。
2. 检查 `.app` 同级的 `build-invocation.json`、`build-result.json`、`build.log`、`unity-console.log` 与 `build-info.json`。Manifest 的 `version` 为 `0.4.0`；`enabledScenes` 有七项，包含首页、庭院与旧五关，首页为首项，排除 SampleScene。构建期间不修改源码或文档。
3. `build-result.json` 的通过只代表产物核验，`applicationSmoke` 为 `not_run`。实际启动该轮 `.app`，确认首先进入首页；完成 Part 1 的庭院主线、至少一次移动误调恢复、机关重复点击、Playing / Completed 重开和返回首页。
4. 在独立应用再检查 Part 3 的中文、分辨率与按钮响应，并完成 Part 4 的旧五关核心机制和下一关链。
5. 另存独立应用的实际操作记录、截图/录像及日志，关联本次 `.app` 路径；不回填脚本结果。构建成功、`.app` 存在或 manifest 正确，均不能替代启动与完整操作结果。

`WSLICE_BUILD_OUTPUT` 可指定新的 `.app` 路径。Editor 菜单 `WSlice → Build/macOS Standalone` 则默认仍输出 `WSliceProto/builds/macos/W-Slice.app` 及同级 `build-info.json`；它不经过脚本的独立运行目录和完整证据核验，须单独记录。

## 快捷键

| 键 | 作用 |
|---|---|
| **R** | 重开（Playing / Completed / Failed） |
| **N** | 下一关（Completed 且该关绑定了可用的 catalog 下一项；庭院独立试玩无下一关） |

## 自动化与五人试玩的证据边界

```bash
./scripts/validate-local.sh --tests
```

自动化包含首页、庭院状态与完整路线、误调恢复、旧五关机制和流转。必须保存本次完整 NUnit XML、实际通过/失败数量及日志；无 XML、陈旧 XML、全部 skipped 或仅退出码为 0 均不算通过。自动化不能代替屏幕可读性、独立应用操作和陌生玩家理解度验收。

五位陌生玩家试玩当前 **0/5**，另行邀请实际未接触项目的人执行；不展示本文工程解法，不口头指导。逐人记录首次理解操作时间、卡点、提示使用、通关时间，以及对“切片改变空间、机关保留结果”的复述。目标约 5–10 分钟；至少 4/5 人独立完成首段教学、至少 3/5 人完成组合谜题并说明关系，才考虑扩关。开发者或 AI 冒烟不计入人数。
