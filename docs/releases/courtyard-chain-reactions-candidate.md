# 庭院连锁反应候选（2026-10-23）

基线：`79c1d0d`，分支 `codex/courtyard-risk-feedback`。接续[回响风险反馈](courtyard-resonance-candidate.md)，加强冒险成功后角色、机关与环境的共同回应。

## 玩家能看到的变化

- 启动机关时，青色能量沿机关、上层平台、坡脚、庭院、桥头、出口平台、终点依次传播；七个晶体节点展开花瓣。桥侧灯随真实桥体升降，光效不改变图路线、碰撞或机关解锁规则。
- 首次获得一条有向路线的风险奖励时，连响升一级，最多三级。稳行不打断连响，重复已领路线不升级；失败清空当前连响。回响仍按原规则奖励 1 或 3 枚，连响没有额外货币奖励。
- 每次冒险成功有三段扩散环、向上喷发的晶体和短暂花冠；级别提高时增加传播波、晶体数量和声部，三级拥有更完整的上行音阶与延长和弦。
- 场景节点显示三层冠环：未达到的层为暗细线，随身未存的层为金色脉动，已存层为青色实环。机关存入会保存当前连响级；失误收回未存层，保留已存成果。通关波从出口反向回应机关，不恢复已丢失的最高级，也不给稳行玩家补发风险级。
- 静音会立刻停止声音并取消排队音符，视觉阶段继续。失败、重开会取消待播胜利音画，避免失败时仍播放成功尾音或重开后场景又亮起来。

传播波、晶体和声音使用固定容量池：12 组传播波、114 个场景装饰 Renderer、6 个声部、24 个延迟反馈事件。所有世界反馈无 Collider，处于 Ignore Raycast 层。

## 实际窗口检查
