# 回响风险反馈候选（2026-10-23）

基线：`1bc513c`，接续 `6fe8ac9` 的移动连续性修改。分支 `codex/courtyard-risk-feedback`。这一轮将庭院推进成可选择的风险奖励玩法；没有更改六关的图路线、场景资产、W 可通行区间或旧版本产物。

## 本轮玩法

- 真正走完入口、阶梯或桥的一段，收集一枚回响。接受点击、原地重复点击和反复走同一方向都不重复发奖。每条切片边的两个方向分别结算。
- 每条有效 W 区间外侧各 20% 为橙色蓄能区。穿越中累计停留 0.30 秒，金环充满，本次成功落地奖励变为三枚。选择青色中央区可稳定通过。
- 橙区会消耗脚下稳定环；从满环连续停留 0.85 秒就崩解。回到青区按每秒 1.5 的速度恢复稳定，已蓄好的本次奖励保留。判定只看实际 `CurrentW`，不看滑条目标值。
- 崩解或调到可通行区间外时，角色返回当前路段安全起点，随身晶体散开并丢失。丢失的方向奖励可以重试获得，已存入的方向不能重复刷取。
- 首次启动机关、再次走到已激活机关、到达终点时存入随身奖励。失败不会撤销机关解锁或已存回响。R 重开清空本局全部奖励。
- 奖励表现为环绕角色的金晶体，存入后飞向机关并呈现青环；落地涟漪、蓄满金环、低稳定提示、失败碎片、终点花瓣和短音表达实际事件。HUD 用晶体格显示本局成果，通关仍保留。
- 音按钮只静音本组件音效。没有相机震动或屏幕闪烁；特效均无 Collider，且置于 Ignore Raycast，粒子和声部池有固定上限。

这是一轮可玩机制迭代，尚不能据此断言玩家留存或趣味性已经提升。真实玩家验证仍未执行。下一轮应观察玩家能否仅凭色带和环理解“蓄满后回中间”，以及 0.85 秒的压力是否合适。

## 验证口径

本机未安装 Unity Editor 6000.0.77f1。标准 `./scripts/validate-local.sh --tests` 明确返回 NOT RUN，不能继承历史构建或测试通过记录。

为检查当前代码，使用临时下载的官方 .NET 8 runtime、Roslyn 与旧 Unity player 自带的真实 managed 依赖，在隔离目录重编全部五个游戏程序集，并编译测试源码。纯模型使用真实 NUnit 断言运行；不会将该结果称为 Unity Test Runner 结果。

另外克隆历史 Mono player 外壳到新目录，替换当前源码程序集运行实验候选。场景、材质和引擎仍来自历史外壳，因此这是“当前源码 + 旧 player 外壳”的实验验证，不能称为 Unity Editor 重新导出、完整发布构建或签名公证版。原应用与历史证据不变。

临时 native harness 在实验编译副本内启用，受启动参数保护，以真实场景、真实移动协程和 Update 执行庭院 NUnit 断言。它不属于产品源码，不进入正式构建。
