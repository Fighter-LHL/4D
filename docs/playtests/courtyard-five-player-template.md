## 预先确定的验收门槛

同时满足才进入扩关阶段：

- 至少 4/5 人独立完成首段教学：自主使用切片并进入庭院，主持人没有提供玩法帮助。
- 至少 3/5 人完成组合谜题，并能用自己的话说明机关状态如何保留、换切片如何利用它到达出口。记录原话，不要求使用“四维”术语。
- 产品内提示允许使用，但必须记录级别和次数；主持人解释或代操作不得计为独立完成。

汇总须区分“带提示可完成”与“自主观察后能解释”；提示级别为 0 也不等于没有默认教学。依据参与者原话和时间戳记录判断，证据不足则标记“无法判断”，不改变上述通过门槛。

操作时间、愿不愿意继续及其原因作为诊断信息记录，不另设通过比例。阻断 bug 单独列出并修复，不能用通关人数抵消技术缺陷。

未达门槛时，按真实卡点修订操作反馈、空间表达或谜题顺序，再找五名新参与者复测。不得事后调低门槛让本批结果通过；五人的定性试验只用于这一轮设计决策，不是市场需求验证。
