# 回响庭院：代表性切片解谜

目标：陌生玩家通过观察空间变化、激活机关、返回并换切片使用机关结果完成一关。预期 5–10 分钟是设计目标，不是已测量结果。

## 入口与操作

- Unity 6000.0.77f1，项目 `WSliceProto`。从 `LevelSelect` 点击“开始：回响庭院”，或打开 `CourtyardSlice.unity` 后 Play。
- 点击地面或落脚点移动，拖动底部滑条切片；到机关旁点击机关/“启动机关”。“提示”按当前阶段逐级揭示，R 重开。
- 原五关保持原有次序；庭院独立完成，结算提供重试与关卡选择。
- 中文界面在 macOS 使用系统中文字体。正式打包后仍需检查字形、布局、按钮和视觉效果。

## 作者规则（给实现与测试人员）

| 路段/动作 | 条件 | 对玩家的反馈 |
|---|---|---|
| 入口 → 庭院 | W ∈ [0.20, 0.40] | 入口门显露通道 |
| 庭院 → 石阶脚、桥头 | 所有 W | 永久安全落脚处 |
| 石阶脚 → 上层平台 | W ∈ [0.70, 0.90] | 倾斜石径出现，其表面与移动线段重合 |
| 上层平台 → 机关 | 所有 W | 平台始终支撑角色 |
| 启动机关 | 角色抵达机关节点且实际位置一致，Playing | 机关倾转、桥头信号亮起；状态跨切片保留 |
| 桥头 → 对岸 | 机关已激活且 W ∈ [0.45, 0.60] | 桥面与地面齐平、碰撞和通行同步；否则桥面沉下 |
| 对岸 → 出口 | 所有 W；完成还要求机关已激活 | 中文结算，返回或重试 |

移动途中把路线切掉时，庭院返回当前线段的安全起点，保持 Playing；原危险关仍采用 Failed。重开时图、W、角色、机关、教学和提示一起恢复。

## 实现边界

- `CourtyardLayout` 定义节点与区间；`CourtyardWorldView` 使用实际运行图决定门、石径和桥的显示。运行时创建几何，已提交场景提供相机、灯光、输入、滑条和结算接线。
- 运行时根节点保持单位变换。`CourtyardSliceGenerator.Generate` 可重建场景壳与定义，原五关数据不作为新关状态源。
- 这是固定布局：节点坐标不可单独移动；修改布局时必须同步几何。校验器会拒绝与 `CourtyardLayout` 不一致的资产，避免角色路线偏离地面。
- 图的 `IsLocked` 默认 false，兼容旧资产；解锁和重开深拷贝保留该状态。`ILevelCompletionCondition` 是可选的通关附加条件。
- 新关点击只响应射线最前方的目标，不穿墙操作远处机关。旧关输入保持兼容。
- 新关没有诊断线路、内部节点名或自动显示的 W 数值答案；按需提示和教学随实际动作推进。
- 当前仍是基础几何和材质，没有正式音效、美术、存档或跨平台交付。
