## Final audio clock contract

`GameAudio.syncWave(snapshot.wave, blocked)` is called after events and UI updates every frame. `blocked = paused || document.hidden`; user pause, help, and restart confirmation set paused, while automatic choice/result dialogs allow the outcome melody to finish. Model updates still stop for every modal. Visibility changes synchronize sound immediately, without waiting for a background frame. Warning beats follow remaining model time, cancel on pause/finish/mute/reset, and do not catch up by replaying missed beats.
