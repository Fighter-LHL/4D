# 构筑隐藏路线与隐星试炼契约

2026-10-23 网页实现。规则权威为 `src/model.js` 与 `src/rooms.js`，Canvas、界面和 Web Audio 只消费快照与事件。本文件补充[遗物联动基线](SYNERGY-CONTRACT.md)；历史契约及验证数量保留，新增规则以本文和[本轮验证记录](artifacts/hidden-routes-20261023/validation.md)为准。

## 三种构筑打开三处入口

每庭新增跨层稳定的隐星台 `rift`。未解锁时只显示不可通行的轮廓及封印，不能通过点击或选择越过封锁。三种隐藏桥分别接在不同锚台；有遗物还不够，必须在本庭实际完成对应操作。

| 隐藏路线 / ID | 同时拥有 | 本庭动作前置 | 三印入口 | 逻辑 W 顺序 |
| --- | --- | --- | --- | --- |
| 棱镜回廊 `prism-coil` | 回流棱镜 + 接力线圈 | 用棱镜**或**线圈实际远程启动过至少一个机关；空放能力、仅接收供能不算 | 维度锚台 `relay` | A → B → C |
| 影织暗径 `shadow-weave` | 留影扣 + 织桥种 | 在归响台／维度锚台借仍存活的机关影子完成一次远程种桥；仅留影或亲手种桥不算 | 归响台 `hub` | B → C → A |
| 护生险径 `shell-weave` | 缓落壳 + 织桥种 | 已种出至少一座桥，并完整通过本庭花匣挑战；不要求消耗护壳，也不要求远程种桥 | 花匣基座 `vault` | C → A → B |

A/B/C 是模板角色，经种子排列后才对应实际潮汐／回声／绽放层；界面与三枚印记显示本庭实际顺序。隐藏桥属于该序列的最后一层。拥有两件不同遗物最早发生在第二庭，第一庭仍能沿完整基础路线前进。

在对应入口、没有穿越或回波时，必须从另一**实际实体层**切入下一印的 W。站在正确层不动、重复赋值、离开后只进层间隙再回来、走路时扫过目标层都不会补印。进入错误实体层会重置为 0；若错误层恰好是序列第一层，则以它重启为 1。中间进度离开入口后保留，普通失稳后也保留；再次在入口进行错误换层仍会重置。

第三印完成立即提交隐藏桥 `entry ↔ rift`。开路不花新货币、不自动完成主线机关，也不直接发奖励。已解锁桥、实际操作资格与印记进度属于本庭持久状态，影子到期、普通失误不会撤回；新庭／新一局清空。三种入口都通向同一隐星台，因此本庭打开多条隐藏路线也只有一次隐星试炼。

## 自选的三波高风险试炼

到达隐星台后不会自动开始。玩家站在实际实体层并持有至少 **2 点随身回响**，主动交互才扣除 2 点入场投入，进入本庭一次性的试炼。已存成绩不参与支付，资源不足时可沿隐藏桥返回收集。

- 三波各 **2.8 秒**，每波恰有一个安全实体层，顺序为本庭逻辑 **B → C → A**，其余两层同时危险。
- 每一波开始后都要从另一实体层**实际切入本波安全层**，并在冲击时仍有该层支撑。即使开始时已经站在安全层，也必须先换到另一实体层再切回来；层间隙往返不算重新入层。
- 一、二波成功只有 `dodge` 和下一波预警，没有部分货币、脉冲、桥种、风险连响或升庭演出。第三波也成功后才提交一次 **9 点回响**，这笔挑战自身的净收益为 7；往返穿越的方向收益独立结算。
- 完整成功使用唯一风险身份 `rift:escape`，按原风险规则增加连响，并在装备允许时产脉冲／桥种；若本庭尚未触发首次风险生长，也触发原有花匣—锚台连锁。后续升庭阶段不会再次发钱或产资源。
- 任一波失败，本庭机会记为失败，入场投入不返还。普通损失仍适用；缓落壳保住扣除投入后剩余的回响和回程结，不能退回 2 点、恢复试炼或把部分躲波算成成功。

预警期间所有端点含 `rift` 或 `vault` 的桥关闭，不能沿已开的隐藏桥、花径或升庭桥逃掉当前回波；移动、存入和主动遗物都被阻止，W 切换仍可用。失败后停回稳定的隐星台，原隐藏桥恢复，可以按所属 W 原路返回继续主线；整局生命耗尽则结束。失败不会把玩家送到未解锁的出口。

## 成功改变场景与后续路线

全胜在提交奖励后安排三个模型时间阶段，暂停不推进。它与第一次风险产生的花径连锁是两套独立、不会重复产奖的世界变化。

| 全胜后时间 | `ascension.stage` | 真实场景变化 |
| --- | --- | --- |
| `.2s` | 1 | 隐星台展开，归响台升起晶柱与拱环，星光冠幕连接第一站 |
| `.65s` | 2 | 维度锚台升起第二组晶柱，冠幕向远端延展 |
| `1.1s` | 3 | 庭门展开金色门冠，加入隐星台—庭门的**升庭桥** |

升庭桥 `rift ↔ exit` 属于庭门的实际 W 层，必须切到它所在层才能走；**仍需本庭三机关全部启动**才开放。可以先赢试炼并长桥，再沿原路补齐机关，也可全部启动后赢试炼，直接走新桥去下一庭。冠幕与前两阶段的光路是悬空演出，不是可走表面。

普通失稳保留已提交的升庭阶段和待到达任务，取消旧庆祝不撤掉晶柱或桥。失去整局后任务不再推进，旧声效被清理；换庭与新局清除旧任务。进入新庭重建本庭状态，已有遗物、已存成绩与剩余回程结按既有规则保留。

## 网页接口与音画边界

快照新增 `hiddenRoutes[]`（`id/name/requires/entry/sequence/progress/unlocked/eligible/requirement/edge`）及 `rift`（`status/stake/reward/canStart/sequence/ascension/exitEdge`）。`wave.variant === 'rift'` 时额外有 `entered`，供界面区分“层正确但还未完成本波换入”与“已换入”。

事件为 `secret_seal {id,stage,from,to,node,layer}`、`secret_open {id,from,to,node,layer,edgeId}`、`rift_start {node,stake}`、`rift_clear {node,value,tier,layer,steps}`、`ascension {stage,from,to,node,layer,edgeId}`；奖励仍走既有 `reward`，并携带 `challenge:'rift'`。三次印记声只跟随真实入层，解锁没有独立计时器替玩家补完。回波使用分阶段的双脉冲，清晰区分两层危险；新预警取消旧奖励和收束华彩。

`rift_clear` 只给无音高的释放声，独立 `reward` 才播放一次较低冲击与更宽上行音型；三段升庭随模型事件逐站发声，第三段以宽声场和弦收束，不再重复完整奖励旋律。24 声部与 `.65` 主增益保持不变。普通失稳保留已提交印记、开路、升庭的物理声音；静音、暂停、整局结束、换庭与重开都清理旧声，恢复不追播。减少动态模式保留实体状态与危险读法，降低运动幅度。

测试数量、实际浏览器操作和截图见[本轮验证记录](artifacts/hidden-routes-20261023/validation.md)。声音自动化验证调度、取消和数量约束；没有把它记为主观听感验证，也不代表陌生玩家已理解或认可玩法。
