# 中转站操作复查与修正

日期：2026-10-23。基线：main `072df20`。

本轮用浏览器真实按键、鼠标和镜头拖动复查操作，再用本地 Chrome + SwiftShader 重复验证。测试探针只读取坐标和机关状态；通关通过键盘移动完成，没有传送角色或直接改写机关。

## 已复现并修正

| 操作 | 原表现 | 修正后 |
| --- | --- | --- |
| 点击音效，移动到晶核前，按空格 | 角色能走，但空格再次切换音效，仍然空手 | 恢复移动或 Q/E 操作后，焦点回到场景；按钮仍支持 Tab、Enter、空格访问 |
| 查看提示后拿起或放下晶核 | 提示被操作消息立即替换，且最多显示 6 秒；重看会揭示下一档 | 提示保留在独立面板，重看不升级；下一档和完整解法均需明确点击，可用 H 或 Esc 收起 |
| 供电、穿过北口，仍在暖 W 时按 F 操作回廊开关 | 提示“晶核不在当前层” | 提示和动作区指出“回廊开关不在当前 W”；已打开时说明会保持开启 |
| 携核撞实墙，放下后贴近墙再拿 | 把实墙受阻归因于携带；上方写“按空格拿起”，底部却显示空间不足 | 撞墙消息不猜测归因；拾取标签使用实际交互判定，空间不足时与动作区一致 |

保持原有碰撞、W 安全检查、机关开闭条件、携带半径和自由放置规则。附近有可拿取晶核时，失败机关说明不会盖过有效拾取。

## 验证

- Node 测试 53/53；全部网页模块语法与 Git 空白检查通过。
- 中转站完成拿取、插座供电、暖 W 穿门、错误 W 操作、切回 W0 开回廊、返回取核和交付的连续流程。
- 贴墙放下后退开能重新拿起；已锁存回廊重复交互不会改变机关或物体状态。
- 鼠标点音效后移动、空格拿取成功，音效状态没有再次改变；键盘仍可操作提示按钮。
- 提示在拿放消息与 6.5 秒等待后仍保留；收起和重看不增加提示层级，完整解法只在明确点击后显示。
- 三章 10 关、无门取物、原理实验室共 12 个其他入口检查了提示展开、下一档、收起、重看和返回章节；第二章的地图与 W 辅助保持隐藏。这不是其他关卡逐关通关记录。
- 1280×720 和 390×844 下提示面板没有横向溢出；静止提示面板、胜利状态及返回标题后不新增 RAF，pending 为 0。浏览器错误列表为空。

过程脚本、复现截图和报告位于本地忽略目录 `output/playwright/playtest/`，其中 `before.json` 记录原版开关错误反馈，`after.json` 与 `chapters.json` 记录修复后结果。

这是功能和反馈一致性的操作检查，不能替代首次接触玩家的理解与趣味性评价；真机触控、Safari/Firefox 和长期性能未在本轮验证。
