# 中转站环境与机关动画

日期：2026-10-23。第二轮基线：`0ab55aa`；该提交保存了上一轮的引导、路线印记、交付后自由走动和触屏布局，随本轮一起合入 main。

## 场景与动作

平台边缘增加常亮角灯、铜边和石缝铆钉，地面增加磨损、矿物色斑、检修盖与电缆卡扣。角灯位于行走边界外，其余细节为表面材质。

放入晶核后，插座触点在 900 毫秒内收拢，亮点沿电缆传向门口；取回晶核时，触点展开，脉冲反向退回。连续拿放会从当前触点位置反转。回廊拉杆用 700 毫秒转到锁存位置，同时沿线路亮起一次。交付时，接收台夹爪跟随已有的 280 毫秒抵达反馈收拢。

动画只读取实际机关状态。通电和锁存仍立即按原规则改变通行条件，操作不等待动画。选择“减少动态效果”时直接显示最终姿态。重开、返回章节和切换关卡会清除动画；静止页面不持续请求动画帧。

本轮保留关卡、碰撞、W 吞没拒绝和第二章隐藏辅助的规则。新增环境细节不标注安全 W 范围。

## 试玩修正

实际键盘试玩完成插座供电、取回再供电、穿北门、拉开回廊、返回取核和铜路交付。断电后北门恢复关闭，回廊保持开启，接收台记录铜印；内置浏览器控制台无错误或警告。

转动镜头后，接收台的路线印记曾被画面右边缘截掉。现在按场景画布的宽高限制印记位置，窄屏时也避开 W 滑轨。

390 像素宽的画面里，交付提示会与“再走另一条”按钮重叠。提示现放在场景上沿，留出底部动作区。
