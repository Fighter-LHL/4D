# 遗物、机关与场景生长契约

2026-10-23 网页当前实现。规则权威在 `src/model.js` 与 `src/rooms.js`，界面、Canvas 和 Web Audio 消费快照及事件，不自行决定开路或奖励。本文件补充 [RANDOM-ROOMS-CONTRACT.md](RANDOM-ROOMS-CONTRACT.md) 的随机房间基线；旧契约、测试数量与截图作为历史保留，冲突处以本文为准。

## 保持不变的空间与短局范围

- 原生网页、三庭短局，四种手工模板取三种且不重复；种子决定模板顺序、实际 W 层排列、合格空间朝向和三种花匣挑战。没有任意程序地图或四维物理引擎。
- 三个实际层中心仍是 `.18 / .50 / .82`。文中的 A/B/C 表示模板逻辑层，实际颜色随种子排列。普通平台使用连续截面支撑，同位机关通过真实 W 切换交接；桥只在指定层可走。
- 归响台 `hub`、维度锚台 `relay`、花匣基座 `vault` 是跨层稳定锚台。稳定支撑不代表任意 W 都可操作机关、触发线圈或走桥。
- 能量在供源启动 `.5s` 后到达下游；所有必需来源都到达才能供能完成。三机关都已启动才允许出口。每个模板保留不使用遗物能力的基础解法。
- 开局与两次庭间选择各取一种遗物或升阶一次。不同遗物同时保留，同类最高三阶；本局仅三次选择，不代表一局必定能获得全部五种。

## 五种遗物

| ID / 名称 | 触发与作用 | 每庭预算或容量 |
| --- | --- | --- |
| `prism` 回流棱镜 | 新风险来源产生脉冲；在 `hub/relay` 主动消耗 1，启动当前实体层已完全供能、未启动的机关 | 持有容量等于阶数；无脉冲不能使用 |
| `shadow` 留影扣 | 站在已启动机关，消耗 1 未存回响，留下该机关的影子，按本模板开启临时捷径 | 每庭一次；持续 12 / 18 / 24 秒 |
| `coil` 接力线圈 | 已收齐能量的下游先蓄势；人在稳定锚台，从另一实体层进入目标层时自动启动 | 每庭最多等于阶数的接力次数 |
| `weave` 织桥种 | 新风险来源产生桥种；在已启动机关消耗 1，种出本庭永久的机关—锚台／归响台桥 | 桥种容量等于阶数；每个源机关每庭只能种一次 |
| `shell` 缓落壳 | 失败时自动保住随身回响与本次回程结损失 | 每庭保护次数等于阶数 |

新庭保留遗物等级、已存成绩和剩余回程结；清空上一庭的脉冲、桥种、影子、永久织桥、线圈蓄势／使用次数、场景生长、机关、风险身份与待执行事件，按现有等级刷新本庭次数。新一局清空整个局内状态；最佳成绩和声音偏好的浏览器存储不属于构筑存档。

## 接力线圈：换层成为机关动作

线圈只给有上游依赖的下游机关蓄势。独立供能源初始已供能，不获得免费自动启动；双源汇流收到第一路时也不能蓄势。模型必须实际处理完最后一个必需的延迟 `power` 到达，且本庭还有线圈次数，才把目标加入 `coilArmed`。

触发同时要求：

1. 玩家没有在穿越或躲波，当前位于有支撑的稳定锚台，包括挑战已经结束的花匣基座。
2. W 真正进入一个受实体支撑的层，且与上一次真正进入的实体层不同。最近层标签改变不等于实体入层；层间隙来回、在同一层重复赋值都不能触发。
3. 目标在新进入的层、仍未启动、仍完全供能且已蓄势，线圈还有每庭次数。

成功先消费一次次数，再发 `coil {from,to,node,layer}`，随后执行普通机关启动，发 `activate/chain`，其中 `via:'coil'`。该机关仍会为它的下游安排 `.5s` 后的真实供能，也能完成出口前置。最后一次用完后清空蓄势集合，此后到达的供能不会再留下可用蓄势标记。

线圈不会在“等能量时一直站在目标层”自动触发。需要在供能到达后实际离开再进入目标层；穿越或预警中记录的入层也不会在状态结束后补触发。它改变跑图路径，保留观察、等待和 W 选择。普通失败保留已蓄势目标与已花次数，不能靠失稳刷新预算；手动或棱镜先启动目标则移除它的蓄势。

## 织桥种与留影代种

桥种只来自有资格的新冒险穿越或完整花匣成功，取得时增加 1，最多持有当前阶数。稳行、重复来源、部分闪避、机关连锁、桥的生成都不产桥种。容量已满的收益仍消费其风险来源身份，不能稍后回刷补种。

本地种桥必须站在有支撑且已启动的源机关，没有在穿越或躲波，有桥种，且该源本庭尚未种过。扣 1 桥种与登记源机关同时完成，然后发 `weave {from,to,node,layer,edgeId,remote}`。种桥本身不发移动奖励，也不自动移动玩家。

| 模板 | 各源机关的永久桥目的地 |
| --- | --- |
| 同位接力庭 | `dew → relay`，`bell → relay`，`bloom → hub` |
| 双源汇流庭 | `dew → relay`，`bell → relay`，`bloom → relay` |
| 远端折返庭 | `dew → relay`，`bell → hub`，`bloom → hub` |
| 分源架桥庭 | `dew → relay`，`bell → relay`，`bloom → hub` |

每条织桥是双向边，存在于源机关自身的实际 W 层。它可以绕开原桥的开路条件，因为源已经付出冒险与启动代价；它不能代替未完成的供能或出口全机关条件。新桥连接稳定锚台，换层后仍有安全落脚点。

**留影代种**允许玩家在 `hub/relay`，使用仍存活的机关影子作为种桥源；同样要求源已启动、有桥种、该源未种过。远程种植不要求玩家站在影子所在层，走新桥时仍要进入桥的 W 层。源机关、目标与桥层由同一模板配置产生，不能由界面另选一条不存在的桥。

远程操作不消费额外影子次数，也不延长影子；先前留影仍支付 1 未存回响并使用本庭一次机会。已经种成的桥独立于影子，影子到期或普通失稳只撤临时影桥，不撤永久织桥。没有影子时不能在锚台凭空遥种。

## 第一份新风险收益触发真实场景连锁

每庭第一次取得新的合格风险收益，在结算奖励的同一模型动作中设置 `resonance.triggered`，记录来源节点并安排三个模型计时事件。无需装备织桥种，不另花回响。

| 成功后模型时间 | 阶段 | 场景落点 | 对规则的影响 |
| --- | --- | --- | --- |
| `.25s` | 1 | 归响台 `hub` | 确认落种，记录持久生长阶段 |
| `.6s` | 2 | 花匣 `vault` | 花匣开花，展示将要连接的桥 |
| `1s` | 3 | 锚台 `relay` | 加入逻辑 C 层的 `vault—relay` 双向边 |

事件为 `resonance {stage,from,to,node,layer,edgeId}`；`from` 始终是那次风险收益的来源，`to/node` 是阶段落点。阶段 1/2 的预览不能成为可走表面。阶段 3 的新边也必须满足本庭花匣前置：双源汇流需要 `dew/bloom` 已启动，其余模板需要 `bell` 已启动。因此早期冒险可以先种下连锁，主线前置未完成时桥仍关闭。

原花匣—归响台桥在逻辑 B 层，新增花匣—锚台桥在逻辑 C 层。玩家可在成功后选择回起点存入，或换 W 去锚台继续主线；它们由不同实际桥承载，不是加分提示。后续新风险仍能按资格产脉冲／桥种和奖励，但不会再次安排这轮生长。

生长已经提交后，普通失稳保留现阶段及未到达的后续阶段。游戏仍在进行时它们继续随模型时间推进；暂停不推进，失败导致整局结束也不会在后台继续演出。换庭或重开清空旧任务。生长不自动启动三座主线机关，不发额外货币，不替代任何花匣闪避，也不产生新的风险来源。

## 通行与选择的一致性

- 花匣预警期间，**所有端点含 `vault` 的桥**一律关闭，包括已经长成的花匣—锚台桥。移动、存入、主动遗物与线圈触发均阻止；仅 W 切换仍可用于躲波。完整成功或失败后按机关状态恢复各桥。
- 同一对节点可能同时有普通、影子或织成的桥，且各自属于不同 W。模型优先选择“已打开且当前 W 支撑”的边，再用其他开放边提供换层提示；不能由数组中的第一条错误覆盖当前可走的边。
- 一旦出发，穿越锁定具体 `edgeId`、层、通行窗口和实际来源，沿它判定支撑与失败。只有这条桥可以显示 `committed` 实面，不能连带把同端点的关闭桥画成实体。
- 影桥到期只阻止新进入，保留已踏上段直到落地。被动的世界生长、延迟供能、线圈接力和影子到期不覆盖玩家仍有效的主动目标选择；建议路线与实际可走边使用同一模型状态。

## 风险身份、失败与重置

方向收益键是 `from>to`，花匣成功键是 `vault:escape`；同一对端点换桥或换 W 不产生一个新方向。未存／已存货币来源和一次性风险来源分别登记。`pulseClaims` 记录已经结算的风险资格，普通失败、存入、支付、影子消失均不清除。

已获得资格的风险来源最多产一次脉冲／桥种，也只有第一次能启动本庭生长。未存货币失去后可以按基础账本重新挣回，但不会再产这些构筑资源。三种花匣每庭都只允许发起一次，失误不退还机会；追层双涌第一波仅发 `dodge`，不产奖励、脉冲、桥种或场景生长。

| 状态 | 普通失稳后 | 换庭／新一局 |
| --- | --- | --- |
| 未存回响／当前未存来源 | 无壳则丢失；有壳则保留，并消费一次保护 | 换庭出口先自动存入；新局清空 |
| 已存成绩、已启动机关、完整／部分真实供能 | 保留 | 换庭保留成绩，重建机关；新局全部重置 |
| 待到达 `power/resonance` | 保留已提交任务 | 清除旧庭任务 |
| 未用脉冲、未用桥种、影子、连响 | 即使有壳也清除 | 清除 |
| 已织桥、已提交生长及其阶段 | 保留 | 清除 |
| 线圈已蓄势目标、已使用次数 | 保留；已启动目标不重新蓄势 | 清除，按等级重新分配本庭预算 |
| 已消费花匣、已用留影、风险来源身份 | 保留 | 清除旧庭身份 |

视图取消庆祝不等于撤回已经生效的世界动作。模型不能让失败过滤掉刚提交的 `resonance/weave/coil/power` 事实，也不能在恢复游戏后补发已取消的奖励。

## 音画与验证口径

场景沿模型提供的真实端点画生长信号、平台花瓣和藤桥，线圈标记属于实际 W 机关。桥只在所属层且开放时有实面；永久变化由快照重建，不依赖庆祝粒子存活。减少动态效果降低移动和粒子幅度；新危险清理庆祝，保留可读的危险层与安全层。

声音仍以成功事件播放原有奖励旋律，生长阶段各发短音色并以桥成双音延音收束；编织气流和线圈分层拨弦保持独立，不再叠播完整奖励。普通失败取消奖励声、保留已提交的供能／生长／织桥／线圈声；静音、暂停、失去整局、换庭、重开清除旧声且不追播。没有独立墙钟计时器推进生长，24 声部与 `.65` 主增益上限保持不变。

当前自动化套件 **91 项**：模型与生成 58、声音 22、场景 11。新增回归覆盖线圈真实入层和完整供能、用尽预算、桥种来源与代种、永久状态与同帧失败、预警封闭所有花匣边、并行边选择、生成桥的实际 W 实面，以及声音取消和数量上限。

实际浏览器操作、截图与源码指纹以[本轮验证记录](artifacts/synergies-20261023/validation.md)为准；原随机房间 58 项及旧截图不作为本轮证据。测试与代理操作不能证明人耳听感、陌生玩家理解度或“更想继续玩”，这些仍需真实玩家验证。
