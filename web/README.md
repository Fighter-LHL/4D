# 四维回响庭院 · 网页版

原生 HTML / CSS / JavaScript、Canvas 2D、Web Audio。无需 Unity，无外部库、字体下载、素材请求或构建步骤。

## 启动与测试

```bash
cd web
npm start
# http://127.0.0.1:4173/
npm test
```

需要 Node.js 18+。`PORT=4174 npm start` 可改端口；服务仅监听本机。整个 `web/` 可部署为静态站点，本轮未发布公网。自动化覆盖模型、种子生成、遗物联动、隐藏路线、场景和声音事件；测试数量见[本轮验证记录](artifacts/hidden-routes-20261023/validation.md)，规则测试不能替代真实玩家体验验证。

打开 `http://127.0.0.1:4173/?seed=123` 可复玩指定旅程。种子是 0–4294967295 的十进制整数；首次打开未指定种子时随机生成并写入 URL，刷新会保留相同旅程，“新一局”生成新种子。它复现房间与规则，不恢复半局进度，也不固定玩家的遗物选择。

## 入门章：平面国

打开 `http://127.0.0.1:4173/flatland.html`（庭院顶栏“入门：平面国”）。玩家是 XY 平面上的二维生物，所在高度 **S** 就是下一章 W 的低维类比；主视图画当前 S 的截面，透视时叠加下方虚影。侧视图通常显示完整立体与玩家平面，猜测隐藏形体时暂不揭示立体，保险箱关只显示玩家高度，镜之锁改用 Y–Z 侧视图观察翻转。已实现六关，顺序如下：

| 关卡 | 教的概念 | 星级 |
| --- | --- | --- |
| 访客 | 球的截面随 S 变化，同样大小的圆出现两次 | 点亮三个圆环（对准后需停留 .35 秒）· 30 秒内 · 答对问题并在两侧都对上 r 1.5 |
| 猜猜是谁 | 比较多个高度的截面，辨认立体并验证预测 | 完成三轮猜测和实际验证 · 至少两轮首次答对 · 三轮全部首次答对 |
| 跳出房间 | 平面里封死的房间在第三维上是开的 | 碰到旗 · 换高度 ≤ 4 次 · 不被卡住 |
| 保险箱与守卫 | 从高处看见盒内，再降入封闭空间；守卫只看得见同层的你 | 拿钥匙开门 · 没有被发现 · 透视 ≤ 2 次 |
| 镜之锁 | 平面内旋转保留手性，借第三维翻转可以得到镜像 | 镜像开锁 · 首次预测正确 · 只翻转 1 次 |
| 升维 | 把调 Z 逃出二维房间，类比为换 W 逃出三维房间 | 两次逃离均完成 · 合计切片改变 ≤ 4 次 · 没有被实体挡住 |

访客点亮三个圆环后仍可拖 S，寻找球心另一侧相同大小的截面，再点“完成观察，回答问题”。30 秒星级以三环首次点亮的时刻计算，额外探索不撤销已经获得的计时星；两侧各需要独立停留 .35 秒。

猜猜是谁的三轮是：观察正放立方体的三个截面后选形体；先预测圆锥从高到低的截面顺序，再实际降低 S 验证；先预测斜立方体的中央截面，再观察三角形、六边形、三角形。标记高度允许 ±.12 的误差，须按顺序各停留 .25 秒；快速扫过不能完成验证。选择只能提交一次，答错后仍可完成实际验证并通关，星级按首次判断计数。观察卡记录实际截面，既不自动演示，也不能用答对跳过观察。

保险箱与守卫：按住 **Space** 或屏幕“透视”按钮查看当前高度下方的虚影，松开即恢复；键盘聚焦该按钮也可按住 Enter。虚影不可拾取，不提供碰撞或通关。盒墙存在于 S=0–4，钥匙在 S=1–1.5，出口门在 S=0–2。升到 S=5，在钥匙上方降到 S=1.2 拿取，再升高离开、到右侧出口降下开门。墙会遮住钥匙与守卫视线；两名守卫沿固定路线往返，只在 S=.85–1.55 检测扇形视野或贴身接触。

被发现时，角色与高度回到入口，已拿的钥匙归还盒内，拿取和开门目标重置。回退清除移动、切层和透视输入，恢复期 1.2 秒；旧的按住按键需要先松开。只失去本次“没有被发现”星，仍可继续通关，没有生命、货币或押注。透视次数按每次按住计数，回退不清零，结果页记录次数与被发现次数。声音提供透视低音、拿取/解锁和警示短音；静音、松手、回退及重开会结束透视音。

镜之锁：本关固定在 S=3，专注钥匙的方向和手性。拿起左侧长短边不等的 L 形钥匙，按 **R** 在平面内转 90°；四个方向都无法匹配镜像锁孔。带钥匙站上中间翻转台，按 **F**，首次翻转前从三张图选一个预测；选择会启动绕 X 轴的 180° 翻转。动画共 1.8 秒，经过侧立位置时短暂停留；左侧明确显示“翻转投影示意”，右侧 Y–Z 视图显示钥匙离开平面、再返回的过程。投影不是倾斜钥匙的实时截面；完成时才提交新手性与方向。减少动态效果设置使用三个关键姿态。

预测只记录首次选择，翻完才揭示正误。选错仍可开锁，仅失去预测星；转过方向的钥匙翻转后可能仍需 R 对齐。翻两次会还原，奇数次成为镜像；再次按 F 不重问或改写首次预测。预测和动画期间禁止移动、切层、旋转及重复翻转，按住 F 的键盘重复事件不会连续触发。镜像和方向都匹配、实际靠近锁孔才通关，钥匙嵌入锁孔并显示“已开”。屏幕按钮与键盘均可操作，结果页记录翻转次数、平面旋转次数与预测正误。

升维：先复习“升到 S=4 → 走到旗子上方 → 降回 S=1”。触旗后开始 4 秒过渡，平面转为等距立体，Z 标签渐变为 W，旁白文字说明维度类比。过渡由模型游戏时间推进，期间锁定移动与切片，隐藏标签页时暂停；减少动态效果以关键画面切换呈现。新房间有地板、四面墙和屋顶，墙与屋顶半透明是观察辅助，虚线表示当前 W 中不存在的实体。

这一教学房间使用沿 W 拉伸的盒体，其截面是真实的三维盒体。玩家沿地板在 X/Z 上行走，Y 固定为 .4；换 W 保持 XYZ 不变。地板贯穿全部 W，墙与屋顶只存在于 W≤.58，出口只存在于 W≤.32。换到 W=.82 走出房间，再在外面回到 W=.18 靠近出口。Q/E、滑块与两枚 W 快捷按钮均可操作；切 W 扫描间隔 .005，使用球与盒体碰撞，若会进入墙体便停在接触边缘，短暂显示红色墙轮廓并提示先移开。碰撞不判失败，仍能恢复通关；S 手势净变化 ≥.3、W 手势 ≥.05 才计一次。

两段均完成后才显示“进入正式庭院”。按钮先保留本关最高星级，再跳转 `./?from=flatland`；正式页在存在升维通关记录时显示衔接说明，并照常让玩家选择起手遗物。庭院仍使用新的普通 `GameModel`，初始回响 0、三枚回程结、未启动机关。明确提示操作变化：Z/X/C 换 W、选择落脚点后 Space 穿越、E 启动机关。章节导航同步 URL，刷新可回到当前关卡。教学不引入遗物、货币、生命或押注。

Q / E 或滑块调 S，WASD / 方向键或在画面里按住拖动来移动（镜之锁固定 S）。调 S 时若新截面会与玩家重叠，会停在紧贴处并闪红提示挡住你的物体，不判失败。闲置会逐级出现提示。`?level=guess`、`?level=escape`、`?level=vault`、`?level=mirror`、`?level=ascend` 可直达指定关卡；进度保存在 `localStorage` 的 `wslice-flatland-stars`，按关卡 ID 保存最高星级，插入新关不会抹掉旧关星级或重新锁住已通关的旧关。完成前一关即可进入新关。代码在 `src/flatland/`：`geometry.js`（截面、侧视投影、碰撞）、`perception.js`（巡逻、视线、下方虚影）、`mirror.js`（钥匙、空间翻转与投影）、`ascend.js`（三维盒体截面、碰撞与投影）、`ascend-scene.js`（升维演出）、`handoff.js`（正式章节入口）、`levels.js`、`model.js`、`scene.js`、`audio.js`、`cards.js`、`progress.js`；测试为 `tests/flatland-*.test.js`。本轮全套 189 项测试通过，实际完成升维三星、撞墙恢复以及正式首庭机关链和出口。验证范围见[升维实玩记录](artifacts/flatland-ascend-20261024/validation.md)、[镜之锁实玩记录](artifacts/flatland-mirror-20261024/validation.md)、历史[保险箱与守卫实玩记录](artifacts/flatland-vault-20261024/validation.md)与[猜猜是谁实玩记录](artifacts/flatland-guess-20261024/validation.md)。

## 一局怎样变化

每局从四种手工机关模板中抽取三庭，局内不重复。种子还决定机关与桥归属的 W 层、空间旋转／镜像，以及花匣挑战顺序。只有同时可见的平台间距合格的投影朝向会进入生成结果。

| 房间 | 需要掌握的关系 | 路线变化 |
| --- | --- | --- |
| 同位接力庭 | 引潮泵 → 同位回声台 → 折光花，逐次供能 | 在原地换层接力，再到锚台换层走向远端花台 |
| 双源汇流庭 | 潮汐源与辉光源都送达，汇流台才能启动 | 两个源可换序；先跑独立两支，再回同位汇流台开桥 |
| 远端折返庭 | 启程泵 → 远端回声台 → 同位反照花 | 在远端换层接力，最后返回归响台，从起始层离开 |
| 分源架桥庭 | 架桥泵开路，供能回声台给承光花供能 | 两个源可换序；桥已出现不代表目标已经能启动 |

机关名不固定代表某种颜色层；查看场景切片、路线标记和接收槽。入口预览本局三庭，通关后能预览下一庭并选择新增或升级遗物。基础路线无需使用任何遗物能力；已有遗物、已存成绩和剩余回程结跨庭保留。完成三庭胜利，三枚回程结耗尽失败。

## 四维切片仍是核心

玩家有 XYZ 位置和连续 W 坐标。潮汐层 W=.18，回声层 W=.50，绽放层 W=.82。每庭至少一对机关处于同一 XYZ、不同 W；原地换层会实际改变脚下的机关，不能靠换层领取移动奖励。预设实体的截面随 W 连续缩放，截面半径足够才有支撑。

归响台、维度锚台、花匣基座和已解锁的隐星台跨层稳定，桥仍只存在于指定 W。普通平台离层约 .9 秒会失稳。供能源启动后，能量 .5 秒才抵达下游；双源机关必须等两路均送达。三座机关全部启动才开出口。归响台能存入随身回响，庭门自动存入并结束本庭。

Z / X / C 快速换层；拖 W 或 A / D 连续调切片；1–6 选择邻接目标；Space 穿越；E 启动／存入；Q 使用可用主动遗物。原生滑块保留方向键，焦点按钮保留 Enter / Space。手机直接点击、拖动。

## 可选冒险与后果

每庭配置一种花匣挑战，每局三种各一次。开匣前可看类型和奖励；启动条件随模板变化。开匣后桥暂时收起，基座保持稳定，W 仍可操作。

| 挑战 | 预告与操作 | 成功回响 |
| --- | --- | --- |
| 单层回流 | 2.4 秒后冲击开匣层，切到任意另一实体层 | 4 |
| 追层双涌 | 两波各 2.4 秒；第二波冲击躲过第一波时所在的层，需要再次观察并换层 | 6 |
| 双层封锁 | 2.6 秒后同时冲击两层，只能停在标出的唯一安全层 | 5 |

层间隙不算安全。第一波闪避不给部分奖励，完成整个挑战才结算一次、增加连响并按规则蓄能。失败仍消耗本庭花匣机会。挑战期间所有连接花匣的桥都关闭；结束后原返回桥恢复，已经长成的连锁桥也恢复，但各自仍需切到正确 W 层。不能在倒计时中存入、用遗物或沿桥逃走。

**冒险穿越**是另一个可选挑战：调 W 跟随较窄、移动的通行带。新方向首次稳行得 1，首次冒险得 3；离开支持区会失稳，不能在落地前切层蹭奖励。同一方向已有领取记录时不能再改为冒险奖励。

普通失稳丢未存回响并消耗回程结，已存回响、已启动机关和已经发出的真实供能保留。行走失稳回实际出发位置，静止离层或花匣失误回最近安全锚台。缓落壳能按剩余次数保护损失。已种出的桥和已提交的场景生长不会因这次失误消失；未用的脉冲、桥种、影子和连响会清除。

## 持续构筑

| 遗物 | 改变玩法 | 进阶与代价 |
| --- | --- | --- |
| 留影扣 | 在已启动的机关留下影子，撑开本庭配置的跨层捷径；不同模板通往锚台、归响台或庭门 | 每庭一次，花 1 未存回响；持续 12 / 18 / 24 秒；到期不接受新进入，已踏上的桥段可走完 |
| 回流棱镜 | 新路线首次冒险成功或花匣全部闪避成功时蓄能；在归响台／锚台远程启动当前层已供能机关 | 上限 1 / 2 / 3；每次消耗 1；不绕过完整供能和 W 前置，失败会丢蓄能 |
| 接力线圈 | 下游机关收齐延迟能量后蓄势；人在稳定锚台，从另一实体层切入目标所在 W 层，自动接力启动，省去跑到机关上的一段路 | 每庭最多 1 / 2 / 3 次；双源必须收齐，停在原层或层间隙来回不触发；用尽后不再蓄势 |
| 织桥种 | 新路线首次冒险或完整花匣成功各产一枚桥种；在已启动机关种出通向锚台／归响台的永久捷径 | 容量 1 / 2 / 3；每次花 1 枚，每机关每庭一次；桥在源机关自己的 W 层，必须换层才能走 |
| 缓落壳 | 自动保住失手前的回响和回程结 | 每庭保护 1 / 2 / 3 次；连响、脉冲、未用桥种及影子仍失去，不恢复已消费花匣 |

选择不同遗物会同时保留，重复选择提升等级，最高三阶。新庭刷新每庭次数和房间机关，清空上一庭的待用脉冲、桥种与造出的桥；生命和遗物保留。已存／已消费收益保留身份，未存丢失可挣回，但同一风险来源不会重复制造棱镜蓄能、桥种或生长连锁。影桥在永久返程条件满足后才可使用，避免到期困住玩家。

**留影扣 × 织桥种：** 在已启动的机关留影，走回归响台或维度锚台后，可让尚未消失的影子代种永久捷径。无需再跑回源机关，种好后影子消失也不会撤桥。影子本身不产桥种，仍要先完成新的冒险。

**线圈 × 机关链：** 在远端折返庭先启动启程泵，等能量抵达远端回声台后，在归响台换入它所在层即可启动；再给下一站供能。升到二阶后，还可等待花台收能，再换层接力第二次。选择棱镜则用先冒险、再主动消耗脉冲的方式完成远程启动；基础路线仍能逐个前往机关完成。

**织桥种 × 房间：** 远端折返庭可以从回声台或花台直接种桥回归响台；双源汇流庭可以从任一已启动源直达锚台。打开捷径不会补齐缺少的能量，也不会跳过三机关全部完成的出口要求。同一对节点存在多条桥时，优先走当前实体层已打开的那条。

## 构筑专属的隐藏路线

凑齐两件遗物后，还需在本庭做出对应操作，入口才会响应三印换层。最早可在第二庭开始探索；不取隐藏路线也能沿基础路线通关。

| 路线 | 遗物与实际操作前置 | 换层入口 |
| --- | --- | --- |
| 棱镜回廊 | 回流棱镜 + 接力线圈；本庭用其中任一件实际远程启动过机关 | 维度锚台 |
| 影织暗径 | 留影扣 + 织桥种；本庭借机关影子完成过远程种桥 | 归响台 |
| 护生险径 | 缓落壳 + 织桥种；本庭已种桥并成功通过花匣全部回波 | 花匣基座 |

看入口三枚印记的实际 W 顺序，站在入口从另一实体层逐次切入。层间隙、重复停在同层不算；错误入层重置，若正好进入第一印则从 1 重新开始。中间进度可保留到下次回到入口，普通失误也不清除；三印完成后，最后一印所属 W 上出现到隐星台的永久桥。

隐星台提供本庭一次的自选试炼：主动投入 **2 点随身回响**，三波各 **2.8 秒**，每波只有一个安全实体层；每波开始后都要从另一实体层实际切入安全层，并在冲击时留在其中。开始时已在正确层，也要换出去再换回；只经过层间隙不算。波间只有短提示，全部成功才获 **9 点**，否则没有部分奖励。

失败不退投入，缓落壳只保护扣款后剩余回响与回程结，不能恢复挑战机会。预警中所有通往花匣或隐星台的桥收起，不能存入、用主动遗物或逃离；失败后隐藏桥恢复，可从隐星台沿原桥返回继续主线。打开多个入口也不会增加试炼次数。

全胜后 `.2s` 归响台升柱、`.65s` 锚台回应、`1.1s` 庭门展开，星光冠幕连接庭院，最终长出隐星台—庭门的**升庭桥**。这条桥属于庭门实际 W 层，仍要求三机关全部启动才开放；可以先赢挑战再补机关，也可做完主线后直接走新桥去下一庭。场景与桥属于本庭持久变化，普通失误不会撤回，暂停不推进。

## 冒险让庭院真正生长

每庭第一次取得新的冒险收益，无论是否带织桥种，都会触发一次三段连锁：`.25s` 归响台落种、`.6s` 花匣开花、`1s` 锚台回应，在逻辑 C 层长出花匣—锚台桥。实际颜色随本庭 W 排列变化，原花匣—归响台桥仍在逻辑 B 层。

新桥必须满足本庭花匣的机关前置：双源汇流庭需要两源已启动，其余模板需要回声台已启动。提前冒险可以先让场景生长，前置未完成时新桥仍关闭。成功闪避花匣后，可以换到新桥所在层直接去锚台；回归响台存入则继续走原层桥。生长只发生一次，不重复产奖；随后普通失误保留已成立的连锁和待抵达阶段，换庭或新一局才重置。

## 音画与计时

场景显示当前实体切片、邻层轮廓、连续截面、真实桥网络和双源独立接收槽。冒险成功按“聚光 → 花瓣与冠环展开 → 沿开放桥传播 → 收回奖励”呈现，再让已提交的生长信号逐站开花、藤桥成形。线圈蓄势标记贴在真实 W 机关上，放电连接锚台和目标。新桥只有在所属 W 层且开锁时才显示实面；换层后轮廓仍可帮助观察。

成功声有低音、上行音型和收束尾音；落种、生长、桥成追加模型事件驱动的短音色递进，织桥用空间气流，线圈用分层拨弦。隐藏三印各响本次真实 W 入层的音符，隐星试炼采用三阶段双脉冲预警；全胜只有一段更低冲击与更宽上行音型，升庭按真实场景事件逐站响起，桥成以宽声场和弦收束。线圈自动启动不重复普通机关华彩，中途闪避也不提前播放完整奖励。主增益保持不变，声音无自动背景音乐。

点击开始后解锁 Web Audio；静音不影响规则，减少动态效果设置会降低演出幅度。暂停、帮助、选择和隐藏标签页冻结规则计时；预警和生长阶段跟随游戏时间，暂停取消旧声音，恢复不重播旧庆祝。失败取消旧奖励庆祝，但已成立的世界状态保留，真实供能、生长、织桥和线圈的提交声不会当作未发生。换庭和重开清理旧庭任务与音画；新预警清理庆祝，危险始终可读。浏览器只保存最佳带回成绩和声音偏好。
