# 回响庭院 · 网页版

原生 HTML / CSS / JavaScript、Canvas 2D、Web Audio 游戏。无需 Unity，无外部库、字体下载、素材请求或构建步骤。

## 启动与测试

```bash
cd web
npm start
# 浏览器打开 http://127.0.0.1:4173/
```

需要 Node.js 18+。端口可用 `PORT=4174 npm start` 修改；开发服务仅监听本机。游戏本身是静态文件，可部署整个 `web/` 目录到支持静态文件的站点，无后端需求。本次未发布公网。

```bash
npm test
```

## 怎么玩

1. 选一件本庭遗物；点场景中的岛或“下一步”按钮选择目标。
2. 调 W，让白色光点进入亮起的区间。“对齐切片”可帮助起步，穿越中不可自动对齐。
3. 稳行的区间固定，首次穿越该方向得 1 回响。冒险的区间会移动，及时跟随可得 3 回响并推进连响；稳定度耗尽即失败。
4. 到机关岛按“启动机关”。三座机关全部点亮后，中央归响台通向庭门的桥真实解锁。
5. 回归响台可存入回响。失误回到出发岛，丢失未存收益并消耗一枚回程结；已存和已点亮机关保留。
6. 抵达庭门自动存入，进入下一庭重选遗物。共三庭；第三庭完成即胜利，三枚回程结用尽结束本局。

键盘：← → 或 A / D 调 W；1–4 选当前邻接目标；Space 穿越；E 启动／存入；Q 遗物；Esc 暂停。原生控件保留自己的 Enter / Space 行为和滑块方向键，使用 Tab 可逐项操作。手机可直接点按钮、拖滑块。

## 三种遗物

| 遗物 | 实际改变 | 代价与边界 |
| --- | --- | --- |
| 回流棱镜 | 首次获得某方向的冒险奖励蓄一枚脉冲；在归响台释放，点亮一个未启动机关并连通外环 | 最多存一枚；失败失去；同方向不能通过丢失再刷脉冲 |
| 留影扣 | 在归响台花 1 随身回响开启 7 秒外环，直接在外围岛间移动 | 每庭一次；到期不再接受新进入，已进入段仍可走完 |
| 缓落壳 | 每庭自动保住一次失败前的随身回响及回程结 | 护壳消耗，连响清零，失败穿越不发奖；第二次恢复普通代价 |

已领取的方向不会重复领奖；已存方向一直去重，未存丢失可重新挣回。消费过的方向也保持已领取身份，不能通过花费制造额外收益。所有通行、奖励、机关和失败由 `src/model.js` 决定，场景和音效只消费事件。

## 表现与设备

浮空石庭、晶体／铜铃／花、W 石桥、逐站能量传播、风险分级冠环与粒子、归存汇聚和失败碎裂；声音使用合成音阶、和弦、低音与短促空气层。没有连续自动背景音乐；开始或点击声音按钮后才解锁浏览器音频。静音不影响规则，系统“减少动态效果”会降低演出幅度。

暂停、说明弹窗、遗物选择和隐藏标签页会冻结规则计时。最佳已存成绩及声音偏好保存在本机浏览器；不保存半局进度，刷新会开启新一局。若本地存储不可用仍可正常玩。

## 本版范围

三庭使用同一套可解布局，种子让 W 窗口有小幅变化，可每庭改选遗物。尚无随机地图、两槽装备、完整十二元素或局外成长。原 Unity 文件与历史测试留档，网页运行不依赖它们。实际陌生玩家试玩与主观音效评价尚未完成。
