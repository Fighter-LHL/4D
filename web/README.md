# 四维回响庭院 · 网页版

原生 HTML / CSS / JavaScript、Canvas 2D、Web Audio。无需 Unity，无外部库、字体下载、素材请求或构建步骤。

## 启动与测试

```bash
cd web
npm start
# http://127.0.0.1:4173/
npm test
```

需要 Node.js 18+。`PORT=4174 npm start` 可改端口；服务仅监听本机。整个 `web/` 可部署为静态站点，本轮未发布公网。

## 空间与主线

玩家有 XYZ 位置和连续 W 坐标。潮汐层 W=.18，回声层 W=.50，绽放层 W=.82。预设实体的截面随 W 连续缩放；截面半径足够才有支撑。归响台、维度锚台和花匣基座跨层稳定，普通平台离层约 .9 秒会失稳。此版本是预设四维实体的切片解谜，不是任意四维几何物理引擎。

1. 选起始遗物，在潮汐层从归响台走到潮汐泵，按 E 启动。
2. 保持 XYZ 不动，切到回声层，脚下变成同位的回声台。水泵能量 .5 秒后抵达，再按 E 接力。
3. 回声台打开归响台至维度锚台的实体桥，并向绽放层的折光花供能。经归响台走到锚台，再换到绽放层。
4. 到折光花启动机关，返回锚台，沿新开的桥去庭门。所有起始遗物均可用基础路线通过。
5. 归响台可存回响；庭门自动存入并给一次新遗物或升阶选择。已有能力、已存成绩和剩余回程结跨庭保留。三庭完成胜利，三枚回程结耗尽失败。

Z / X / C 快速换层；拖 W 或 A / D 连续调切片；1–4 选择邻接目标；Space 穿越；E 启动／存入；Q 使用可用主动遗物。原生滑块保留方向键，焦点按钮保留 Enter / Space。手机直接点击、拖动。

## 额外冒险及后果

- **裂隙花匣**：回声台启动后可从归响台前往。开匣后桥暂收回，2.4 秒回流倒计时开始。必须切到潮汐或绽放层有支撑的区域避开，停在层间隙不算成功。成功得 4 回响、连响和棱镜蓄能，失败承担失稳损失。每庭只有一次花匣机会。结束后切回回声层沿桥返回。
- **冒险穿越**：可选移动 W 光带挑战。新方向稳行首次得 1，冒险首次得 3；离开桥的支持区会失稳，不能在落地前切层蹭奖励。
- 失败丢未存回响并消耗回程结；已存、已启动机关及已经发出的真实供能保留。行走失稳回实际出发位置，静止离层失稳回最近安全锚台。

## 持续构筑

| 遗物 | 改变玩法 | 进阶与代价 |
| --- | --- | --- |
| 留影扣 | 在已启动的水泵／回声台留下影子，撑开回声台到锚台的捷径；在花台留影则开花台到庭门的捷径 | 每庭一次，花 1 未存回响；持续 12 / 18 / 24 秒；到期不接受新进入，已踏上的桥段可走完 |
| 回流棱镜 | 新路线首次冒险成功或花匣闪避成功蓄能；在归响台／锚台远程启动当前层已供能的机关 | 上限 1 / 2 / 3；每次消耗 1；不绕过供能和 W 前置，失败会丢蓄能 |
| 缓落壳 | 自动保住失手前的回响和回程结 | 每庭保护 1 / 2 / 3 次；连响、脉冲及影子仍失去，不恢复已消费花匣 |

选择不同遗物会同时保留；重复选择提升该遗物等级。新庭刷新每庭次数，生命不重置。已领方向与已存／已消费收益保留身份，未存丢失可挣回，但不重复制造棱镜蓄能。

## 表现与设备

同位水泵／铜铃替换、跨层支撑柱、邻层轮廓、连续截面缩放、实际桥网络、延迟能量轨迹、影子压桥、收拢的回流环、分级奖励冠环和粒子。三层切换分别发声，接力和成功演出逐级增强；没有自动背景音乐。

点击开始后解锁 Web Audio；静音不影响规则。系统减少动态效果会降低演出幅度。暂停、帮助、选择和隐藏标签页冻结规则计时；预警声跟随剩余游戏时间，暂停取消旧声音，恢复不重播旧庆祝。浏览器只保存最佳带回成绩和声音偏好；不保存半局进度。

## 范围与证据

当前是“三层空间解谜 + 可选风险 + 跨庭构筑”的短局。三庭沿用一套空间拓扑，后两庭仅有通行宽度微调与累积能力变化；没有随机地图、局外成长或完整十二元素。并未进行陌生玩家试玩，自动化通过不代表已验证有趣或主观音效满意。
