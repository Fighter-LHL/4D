## 实际浏览器流程

| 检查 | 观察结果 |
| --- | --- |
| 稳行往返、滑块焦点下按 E | 机关点亮，往返各得 1，回岛成功存入 2 |
| 不调 W 的冒险 | 失稳返回出发岛，回程结减少，已存 2 保留 |
| 通过滑块方向键跟随移动光带 | 获得 3，连响 1 层，棱镜显示已蓄能 |
| 棱镜 Q | 消耗脉冲，点亮剩余机关，外环连通，庭门出现在邻接选项中 |
| 过庭 | 自动存入，第 1 庭结束累计 7；换留影后保留成绩和剩余回程结 |
| 留影 | 花费 1，显示倒计时；抵达外围后可以直接选择另一外围岛并完成跨越 |
| 穿越中暂停 | 进度保持 21%，期间整理文档后仍为 21%；继续后正常到达 |
| 第三庭护壳 | 失稳后护壳消耗，随身 1、已存 13、剩余 1 枚回程结全部保留 |
| 完整胜利流程 | 三庭完成，已存 20；统计冒险成功 1、机关 9、失稳 3；可重新开局 |
| 重新开局后的耗尽流程 | 护壳首次保护；随后三次失误依次剩 2 / 1 / 0，出现结束界面，未存丢失 |
| 画布点击 | 直接点击回声铃岛，页面目的地同步选中该节点 |
| 375 / 320 像素宽度 | 页面宽度分别等于视口，无横向溢出；实际稳行、启动机关、说明弹窗可操作 |
| 浏览器日志 | 上述完整流程未捕获应用 console error / warn |

修复过的整合问题：紧凑桌面中画布过高挤走控制区；穿越后滑块焦点导致 E/Q 等快捷键被过滤；浏览器历史缓存返回时过早销毁音频；重开后读屏状态残留；每帧重建按钮子节点造成间歇性点击落空。按钮改为内容变化时才更新后，实际连续走完第一庭的六次外围往返、点亮全部三机关并存入 6，随后声音开关与新局选择正常。历史缓存音频恢复分支为代码审查，未声称实际往返验证。
