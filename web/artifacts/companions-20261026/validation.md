# 伙伴能力、自由移动与庭院衔接 · 2026-10-26

本轮按用户选择完成伙伴能力、前两关移动和庭院衔接。在已有未提交工作区上增量修改，未提交、推送或发布公网；此前发现、收集与玩法验证记录保留原状。

## 实现

- 跳跳：B 沿朝向探入 S ± 1.5 的邻层，前行最多 2.4，飞行 0.3 秒、停留 2 秒、冷却至 2.5 秒。目标层真实墙体阻断路径；可收集该层光屑、碰开花苞，令附近同层且无遮挡的守卫转向。按钮选择向上 / 向下，越界或起点被墙占据会反馈。
- 瞌睡灯：附近半径 3.2 的 S ± 1.2 精确截面以金色 / 蓝色虚线显示，包括遮挡后的物件；B 扩至半径 5，持续 2 秒。轮廓局部裁剪，不改变碰撞、钥匙拾取和遮挡规则。
- 反反：B 切换左右镜像同步。镜像保持同高、关于房间中线对称；投影位置有实体墙时不能压机关。六个平面场景的对称花垫需两者同时站稳 0.6 秒，释放真实可拾取的金色光屑。上层花苞也会释放一枚光屑；每种奖励每次入场只发一次。
- 所有主动能力、额外机关与额外光屑只在自由探索生效；计分挑战及风暴禁用。暂停冻结时间；切换伙伴、受击和守卫遣返撤销动作；重来重置机关与动作，保留收藏。立体阶段保留伙伴外观，暂停平面能力。
- 访客、变形锁支持 WASD / 方向键 / 拖动连续移动，原截面匹配与挑战评分条件仍在。
- 庭院读取已有 `wslice-flatland-friends`，全部已收集伙伴进入场景。一位伙伴按模型现有的下一步路线标出真实机关或桥所在 W 层，其他伙伴随行；行进和危险回流期间不展示普通路线引导。不导入能力、分数或星级，不自动激活机关。
- 修正 `.actions` 的显示条件：当可见动作只剩“去庭院”链接时，动作栏仍然显示。

主要入口：`src/flatland/companions.js`（模型能力）、`src/flatland/perception.js`（邻层截面）、`src/flatland/friends-scene.js`（反馈）、`src/courtyard-friends.js`（庭院呈现）、`GameModel._companionGuide()`（实际路线）。

## 真实浏览器

通过 Codex 内置浏览器的按钮、滑条与按键操作，未注入游戏状态或伪造收藏。使用此前已实际收集的三位伙伴存档，本轮不声称重新完成了三位伙伴的收集。

1. 访客 `seed=42`，S=1.2，实际移动到南侧花垫，朝右按 B。出现上层跳跳及 S / 停留时间，花苞打开，反反在对称花垫同步停留后打开花匣，三枚金色光屑出现。见 [最终场景](flatland-toys-final.png)。
2. 切入计分挑战，开场显示原星级目标；开始后没有伙伴能力按钮，按 B 不触发能力。规则隔离另由模型对比测试确认。
3. 变形锁使用实际 D 键移动；320 × 740 视口页面宽度和滚动宽度均 320，操作按钮换行，B 按钮底边 735.39，仍可操作。见 [窄屏变形锁](mobile-guess.png)。完成后恢复默认视口。
4. 升维 `seed=42`：S=4 越墙到低层旗子，完成 4 秒过渡；W=.82 越过立体墙，再回 W=.18 抵达出口。实际看到并点击独立“去庭院”链接，见 [升维入口](ascend-entry.png)。该流程曾暴露只有链接时动作栏被隐藏的问题，修正后重走两阶段并验证。
5. 庭院 `seed=513051837` 入场明确显示“跳跳、瞌睡灯、反反也来了”。选择缓落壳后，看到随行伙伴及架桥泵上的引导，实际穿越、启动机关，提示切到Ⅲ层；点击对应层后，同一位置切换到供能回声台，提示 E 启动。见 [庭院伙伴](courtyard-friends.png)、[下一层机关](courtyard-next-layer.png)。
