# 镜之锁验证 · 2026-10-24

实现第五关 `mirror`：拾取 L 形钥匙、平面旋转、首次翻转预测、空间翻转动画、镜像与方向匹配开锁、星级和恢复流程。没有修改庭院模型；第六关“升维”仍锁定。本地改动尚未提交或推送。

## 规则与几何

- 钥匙长短边不等，排除等臂 L 可以通过平面旋转匹配镜像的歧义。R 每次平面旋转 90°，不改变手性。
- 本关固定 S=3；需先拿钥匙，再实际站到翻转台才能按 F。首次 F 打开三张预测图，预测基于当前钥匙方向。选择后自动翻转，直到翻完才揭示正误；之后不能改选。错误答案不阻断通关。
- 绕 X 轴的刚体旋转使用 `(x, y cos θ, y sin θ)`，θ 从 0 到 π；动画中点约 .3 秒的侧立停顿便于观察。左侧明确标作投影，右侧 Y–Z 视图展示离开平面的高度。没有把投影误称为倾斜钥匙与平面的截面。
- 动画由模型游戏时间推进，共 1.8 秒。动画结束才提交手性和方向：`chirality=-chirality`，`turns=-turns mod 4`。预测和动画期间移动、切层、R 和 F 均不能改变钥匙或提前开锁。大帧时间仍最多推进 .1 秒；减少动态效果使用开始、侧立、完成三个姿态。
- 不翻转或翻偶数次，手性不匹配；镜像正确但朝向不对时，R 仍可校正。靠近真实锁孔，钥匙、手性和方向都匹配才完成。成功后钥匙对齐锁孔，锁显示“已开”。
- 星级独立计算：完成 / 首次预测正确 / 恰好一次翻转。第二次翻回原样仍可第三次翻转恢复，首次预测与次数不重置。最高星级按关卡 ID 保存。
