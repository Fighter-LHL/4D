# 平面国：猜猜是谁与访客探索修复

日期：2026-10-24。基于本地尚未提交的平面国两关实现继续开发；Git 基线为 `a34fa34`。本轮没有修改庭院模型或推送提交。

## 实现范围

- 新增第二关 `guess`，顺序为访客、猜猜是谁、跳出房间。其余三关保持未开放。
- 三轮分别为：观察多个截面识别正放立方体；预测圆锥从高到低的截面变化；预测斜立方体的中央截面。
- 首轮必须完成三处实际观察才可回答，未回答前隐藏侧视图中的立体。后两轮先预测，选完才解锁 S；每轮实际验证后才能进入下一轮。
- 高度标记容差 ±0.12，连续停留 0.25 秒才记录一个截面。圆锥使用现有朝上模型，明确从高到低，实际得到小圆、较大圆、大圆、无截面。斜立方体实际得到三角形、六边形、三角形。
- 答案只提交一次；答错仍可验证和通关。完成三轮获得一星，首次正确至少两轮获得第二星，三轮全对获得第三星。
- 访客点亮三环后继续允许探索，由“完成观察，回答问题”进入答题。计时星以点亮三环的时刻结算；两侧截面分别要求连续停留，不复用另一侧的停留进度。
- 星级按稳定关卡 ID 保存，已完成的旧逃脱关不会因插入新关被重新锁住。答题卡使用稳定 DOM，避免 SVG 序列化导致逐帧重建、失去键盘焦点。

## 浏览器实玩

入口：`http://127.0.0.1:4180/flatland.html`。通过界面按钮、原生 S 滑块和按住 D 移动操作，没有注入浏览器游戏状态或调用模型完成关卡。

1. 访客按低到高依次匹配 `S≈0.71 → 1 → 3`。三环点亮后页面保留操作，再调至 `S=5` 找到第二处半径 1.5 截面，主动答题选“两处”。首次调试运行因工具操作间隔超过 30 秒获得两星；随后相同自然顺序快速复测为 **3.8 秒、三星、0 次卡住、0 次提示**。见 [继续探索](visitor-continued-exploration-ax.txt)、[三星结果](visitor-three-stars-ax.txt)、[截图](visitor-three-stars.png)。
2. 从访客“下一关”正常进入猜猜是谁，验证新关解锁。三轮首次均答对，按界面标记完成观察，获得 **三星，首次正确 3/3、猜错 0 次、用时 63.2 秒**。见 [结果](guess-three-stars-ax.txt)、[截图](guess-three-stars.png)。
3. 圆锥作答前滑块确实禁用，作答后可以调整；实际从 `5.25 → 3 → 0.60 → 0.20` 验证由小到大再消失。见 [预测阶段](cone-prediction-ax.txt)、[观察结果](cone-verified-ax.txt)。
4. 斜立方体在 `S=3` 实际显示六边形，在 `S=1.55` 和 `4.45` 显示三角形。见 [最终预览](cube-hexagon.png) 和 [状态](cube-hexagon-ax.txt)。
5. 新关通关后“下一关”进入跳出房间。升至 S=4，按 D 出墙，在墙和柱子之间降到 S=1，再按 D 走到旗，取得 **三星、换高度 2 次、卡住 0 次**。见 [状态](escape-after-guess-ax.txt)、[截图](escape-after-guess.png)。
6. 另一次重玩故意三轮全猜错，仍完成全部实际验证并以 **一星、首次正确 0/3、猜错 3 次** 通关。见 [答错后的继续验证](wrong-answer-recovery-ax.txt)、[最终状态](guess-all-wrong-ax.txt)、[截图](guess-all-wrong.png)。
7. 低星重玩后刷新，猜猜是谁仍显示历史最高三星，逃脱关三星也保留。见 [刷新后的关卡栏](progress-reload-ax.txt)。旧版插入新关前存档的兼容性由自动化测试覆盖，未声称进行了旧版本浏览器迁移实验。
8. 浏览器读取的 error/warn 记录为空，见 [console.json](console.json)。连续操作状态见 [browser-trace.json](browser-trace.json)。
