# Penpal 本机试玩 Top 5（2026-10-27，tip `995a84c`，http://127.0.0.1:4173）

证据：`notes.json` + `06c`–`14` 截图。新档清 `wslice-*` localStorage。未声称“已好玩”。

## 1. 庭院开局被遗物选择大弹窗占满（开局导向）
**复现：** 打开 `/` 新档 → 立刻 `dialog#choice-dialog` 全屏选遗物（随机旅程说明 + 三庭预告 + 遗物卡）。未关闭前 canvas 点击会被 dialog 拦截（Playwright 多次 `intercepts pointer events`）。
**问题：** 首 30 秒是读卡/选构筑，不是“调切片/靠近/试一下”的场景内反馈；设计要求禁止长教程墙，这个弹窗信息密度接近教程。
**改进方向 (A)：** 缩成短确认（遗物名+一句效果），把旅程说明移到可点的「怎么玩」或首次稳行旁白；选完立刻用场景高亮指向第一个供能源。

## 2. 选完遗物后「已供能待启动」与机关 0/3 的下一步仍偏抽象（庭院下一步）
**复现：** 选遗物后 objective=`已供能待启动：潮汐源、辉光源（机关 0/3）`；请求提示后 friendGuide=`前往潮汐源 · 点平台预览，再点稳行`。按 Z/X/C、E、点「稳行/冒险」后机关计数仍易停在理解门槛。
**问题：** 文案正确但场景内缺少“能量到了哪里 / 为什么还不能 E”的即时反馈。
**改进方向 (C)：** 供能槽/连线脉冲；E 失败时短飘字说明缺哪一环；成功启动时机关亮起+计数跳动。

## 3. 平面国访客关几乎没有可读的当面目标（开局导向）
**复现：** `/flatland.html` 点 `1 · 访客` 后 roomName=访客，a11y 无 `#objective`/`#scene-state`；要靠「口袋里的秘密」才看到线索。
**问题：** 新玩家不知道先戳球、调切片还是看口袋；发现伙伴的爽感入口藏在二级面板。
**改进方向 (A/B)：** 访客场景内一条短目标（如「戳一下球 / 拖切片看截面」）；首次打开口袋时短飘字，不要只静默剪影。

## 4. 「怎么玩」仍是大段 MOVE THROUGH W 教程墙（与设计冲突）
**复现：** 庭院点「怎么玩」→ 大 dialog，多段 W/机关/路径说明（见 `10-courtyard-help.png` / notes）。
**问题：** 与「帮助不替玩家解完整题、禁止长教程墙」冲突；且与开局遗物弹窗信息重复。
**改进方向 (A)：** 改成 3 条可点击短提示，按当前卡点只揭示一条。

## 5. 口袋收藏「还没遇见」线索好，但发现反馈加汁不足（发现反馈）
**复现：** 口袋显示三伙伴剪影线索 + 花园 0/6；全是未遇见状态（新档正确）。
**问题：** 线索文案有趣，但关卡内缺少把玩家「推到第一次发现」的场景反馈；从访客到越墙切换时也无发现相关旁白。
**改进方向 (B/E)：** 第一次靠近可发现区域微高亮；发现瞬间声音+短飘字；花园 0/6 在主 HUD 更可读。
