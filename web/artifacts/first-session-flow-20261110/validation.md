# 验证记录 · 首局流程回归保护（2026-11-10）

分支：`codex/onboarding-load-review-20261110`（仅本地，未推送）。

## 为什么重写

旧的首局浏览器脚本按旧交互编写：点“穿越”和“启动机关”按钮、用具名主按钮（“稳行到X / 启动X”）、按 E、焦点落到 W 滑杆。本轮改动后，这些控件都收进了“高阶操控”抽屉，主流程变为：
- 点目标，自动沿当前层寻路；
- 需要换层时停在 ⚓ 台上，由玩家亲手滚轮；
- 登台自动点亮。

旧脚本因此第一步就失败，不再保护任何东西。本轮保留每个脚本原本要保护的意图，改用新流程的真实输入重写断言。

## 共享工具：`scripts/courtyard-first-beat.mjs`

- **只读观察器**：复制快照，记录每帧实际画出的提示气泡、弹窗文字和供能事件；不改模型、计时、收藏或首访预算。
- **真实输入**：点画布上的平台或机关清单行、在画布上滚动真实滚轮、按键、点按钮。
- **`followGuidance`**：一个只照游戏指示操作的“玩家”。它读三步罗盘和画布气泡给出的目标层与滚轮方向，并断言这些指示与游戏实际等待的换层一致，再用真实滚轮照做。走路和点亮必须自动完成，不需要其他输入。
  - 从第 3 阶段起，游戏会故意不说出目标层，让玩家看虚线桥推断。这时它先断言提示里没有泄露答案，再点三步罗盘揭晓提示，然后照做。
- 覆盖平面国发现入口可达的 4 个首局房间：
  - cascade、split：原地换层；
  - confluence：回 ⚓ 归响台再换层；
  - return：经过归响台，停在 ⚓ 维度锚台再换层。

## 各脚本保护的意图

| 脚本 | 覆盖 | 保护什么 |
|---|---|---|
| `verify-first-feedback` | 4 房间 × 3 宽度 | 被拒绝的动作（点 🔒 机关）给出一条不超出屏幕的弹窗，状态栏不重复，读屏播报一致，玩家不被带走；出发后旧提示消失；点亮 ① 不需要按 E，结果播报一次后消失；首局任何反馈都不要求按 E；画布同时最多 2 个完整提示气泡 |
| `verify-first-onward` | 4 房间 × 3 宽度 | 点亮 ① 后的交接：同位房间里，罗盘、画布气泡、高亮的层按钮都指向正确的层和滚轮方向；锚台房间里先提示回 ⚓ 归响台；停着不动时不会替玩家走、换层或点亮；横幅自动收起；暂停冻结；H 显示伙伴提示后消失；照指示操作能点亮 ②，且只换一次层，换层地点正确 |
| `verify-first-return` | confluence × 3 宽度 | 点 ② 后自动走回并停在 ⚓ 归响台，不替玩家换层；停留时弹窗消失，罗盘和气泡留下；往反方向滚，层会变，但玩家不会被带走，寻路也不会继续；往正确方向滚，寻路自动继续并点亮 ②，全程只点过一次（选 ②） |
| `verify-first-anchor` | return × 3 宽度 | 同上，另外确认寻路会穿过 ⚓ 归响台而不在那里停下，唯一的换层指示出现在 ⚓ 维度锚台 |
| `verify-first-exit` | 4 房间 × 3 宽度 | 只照游戏指示就能点亮全部 3 个机关；清单始终标出游戏期待的下一个目标；H 不会代替玩家操作；过桥途中不画任何提示气泡（按每帧实际绘制检查）；终点卡变成“大门已开”，点它进入庭间选择（普通选择框）并写入首局完成标记；重开与回访不会再弹发现入口专属的开局选择 |
| `verify-penpal` | 3 宽度 | 无凭据的 discovery 链接不能伪造入口；新档首局不弹选择框、不出现局中切换遗物；遗物抽屉在所有宽度都能按需展开，手机首屏能放下画布和横幅；按 E 的本地反馈仍然有效；首次点亮在 30 秒内；部分供能只由清单槽位显示；H 的文案使用当前操作方式；远程供能到齐只在一个地方显示；帮助文本不超过 60 字；最后走一遍真实发现入口、开局选择与重开回访；平面国访客部分保持不变 |
| `verify-top5` | 3 宽度 | 平面国部分保持不变；庭院收尾改为：开局选择、照指示点亮 ①、暂停冻结、6.2 秒内不自动弹提示、首访节奏只播 arrival 和 follow 各一次、H 显示后消失 |
| `verify-onboarding-load` | 1280 | 上一轮的 18 项检查（方向、首局遗物、横幅、R/Tab、主题、观测台、放手冒险会失手） |

## 重写过程中发现并修复的产品问题

1. **点一个 🔒 机关会把玩家带去别处**（confluence）。只要碰巧有桥通向它，就会自动寻路过去。现在会直接说明“还没供能：先点亮 ①+②”，不移动。
2. **出发后旧提示不消失。** 点 🔒 被拒后再出发，拒绝提示会一路跟着。现在弹窗带类型：出发时，“被拒”和“换层指示”类提示会被清掉，远程供能消息保留。
3. **读屏播报被覆盖。** 升阶段时，阶段说明写进了 `#announcement`，把同一帧的点亮结果覆盖掉了（上一轮第 4 步引入）。现在横幅自己负责 aria-live。
4. **按 H 看不到提示。** `#friend-guide` 被放进了默认收起的“高阶操控”抽屉，现已移到横幅下方。
5. **伙伴提示还在讲旧操作**（“Z/X/C 换层”“E 启动”“点平台预览，再点稳行”），现已改为当前操作方式（点目标、滚轮上滚或下滚）。
6. **桌面端看不到遗物、庭院生长和隐藏路线。** 最初那批改动把抽屉默认收起，但桌面端的展开标题被 CSS 隐藏了，这些内容完全没有入口。现在所有宽度都能看到并展开这个标题。
7. **手机上点清单看不到结果。** 清单在画布下方，滚下去点一行后，结果弹窗在屏幕外。现在从侧栏点行或卡片时，会先把场景滚回视野。
8. **“供能到齐 · 点它走过去即可点亮”在原地换层的房间里不对**，已改为中性的“点它前往点亮”。
