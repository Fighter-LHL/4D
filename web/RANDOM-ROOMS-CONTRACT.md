# 随机房间与跨层机关契约

> 历史基线说明：本文保留随机房间迭代当时的规则和 58 项测试口径。后续遗物联动、永久桥、场景生长及对应失败／声音边界见 [SYNERGY-CONTRACT.md](SYNERGY-CONTRACT.md)；本文的模板生成、四维支撑和花匣基础规则继续适用，冲突处以新契约为准。

当前实现契约，2026-10-23。适用于原生网页 `src/rooms.js`、`src/model.js`、`src/main.js`、`src/scene.js`、`src/audio.js`。它替代 [SLICE-CONTRACT.md](SLICE-CONTRACT.md) 中固定首庭、固定层归属、固定机关链、固定影桥和单一花匣规则；旧文件及证据作为历史保留。

## 生成范围与复玩

- 一局三庭，从四个手工模板洗牌取前三个，局内模板不重复。
- 三种花匣挑战独立洗牌，每局各出现一次。模板拓扑、实际 W 层排列、空间朝向和挑战都在开始一局时由种子确定；打开菜单或重新进入节点不会重新抽取。
- 每庭把逻辑层 A/B/C 排列到实际层 0/1/2。实际层名与中心不变：潮汐 `.18`、回声 `.50`、绽放 `.82`。机关身份不与某个颜色绑定；桥、实体、危险层、提示与音画都读取同一排列结果。
- 对手工 XYZ 坐标进行水平镜像和 90 度步进旋转，保留同位关系。不是对平台坐标任意采样，也不是自由生成任意连通图。
- 几何继续使用 `screenX=500+(x-z)*52`、`screenY=350+(x+z)*27-y*50`。生成器以共显平台的椭圆足迹筛选朝向：归响台半轴 `112/60`，其它平台 `81/52`；将两者间距分别除以半轴和，所得向量长度至少 `1.05`。不同 W 的两个普通平台允许有意共用 XYZ；锚台始终参与间距检查。没有合格朝向时明确抛错，不能偷偷使用重叠布局。
- URL `?seed=<uint32 decimal>` 复玩同一实现下的同一旅程。缺失或非法种子生成随机数，写回 URL；刷新从相同种子重新开始，“新一局”更换种子。种子不是存档，遗物选择与玩家操作不自动复现。算法或模板后续变更可能改变同一种子的结果。
- 有限模板池允许不同种子得到相同组合，不承诺无限地图或每局绝不重复。

## 四种模板

表中 A/B/C 是逻辑层，实际颜色由本庭排列决定。所有出口都要求 `dew`、`bell`、`bloom` 三机关已启动。

| ID / 名称 | 供能前置 | 永久路线与同位关系 | 花匣开放条件 |
| --- | --- | --- | --- |
| `cascade` 同位接力庭 | `dew → bell → bloom` | A 的引潮泵与 B 的回声台共用 XYZ。回声台打开 B 的归响台—锚台、C 的锚台—花台；出口从 C 锚台出发 | `bell` 已启动 |
| `confluence` 双源汇流庭 | 独立的 `dew` 与 `bloom` 同时向 `bell` 供能 | 两源分别从归响台到达，顺序自由。`dew` 与 `bell` 共用 XYZ。汇流台打开 B 的归响台—锚台；出口也在 B | 两源均已启动 |
| `return` 远端折返庭 | `dew → bell → bloom` | `dew` 打开 A 的归响台—锚台与 B 的锚台—回声台。远端 `bell/bloom` 共用 XYZ；回声台打开 C 的返程桥。最终回到归响台，从 A 离开 | `bell` 已启动 |
| `split` 分源架桥庭 | `dew`、`bell` 都是独立源，只有 `bell → bloom` 的供能关系 | `dew/bell` 共用 XYZ。`dew` 打开 A 的归响台—锚台及 C 的锚台—花台；`bell` 单独给花供能。开路与供能缺一不可，出口从 C 锚台出发 | `bell` 已启动 |

供能源启动后 `.5s` 发送一个到达事件，下游通过 `received` 集合按来源去重。`powered` 必须满足全部 `required` 来源均已到达；双源汇流不能用任何一路提前启动。`power` 事件带 `complete / received / required`，半完成接收有独立表现，不伪装成机关完成。

启动是玩家交互或合格棱镜能力的独立动作；收到能量不自动启动下游。每庭的 `mechanismOrder` 只用于建议和展示，不限制独立两源的操作顺序，也不是通关验证脚本的权威答案。

## 空间与通行

节点保持真实 `world:{x,y,z,w}`，场景使用生成后的投影坐标。切片半径为 `sqrt(max(0,1-((w-center)/.16)^2))`；半径达到 `.5` 才支撑普通平台。归响台、维度锚台、花匣台座跨层支撑，台座上的花匣只在它的 B 层出现。

- 普通平台离层时约 `.9s` 失稳；若同 XYZ 有另一个得到支撑的普通实体，`phase_transfer` 把玩家接到那个实体。接住不要求供能，操作机关仍要求供能。换层不发移动奖励。
- 桥只在所属 W 有效。`availableNodes` 可显示不同层的邻接目标，但 `canMove` 同时检查真实连边、开锁条件、当前支撑与通行窗口。
- 未供能但已同位换入的机关必须保留合法退路。桥的锁定状态只随已完成前置打开，普通失败不把已完成主线重新锁上。
- 稳行与可选冒险共用这些真实连边。冒险通行窗口移动且更窄，途中失稳回该段真实出发节点和 W；不能靠最后一刻换层绕过落点支撑。
- 所有模板必须保留不使用遗物能力的完成路径。可达性验证需包含节点、W、已启动/供能状态，不能只验证初始静态图。

## 留影、棱镜与返程

留影只能放在已启动机关，花 1 未存回响，每庭一次，按等级持续 12 / 18 / 24 秒。捷径由模板定义：

| 模板 | 影子来源 → 临时桥 |
| --- | --- |
| 同位接力 | `dew/bell` → B 的 `bell—relay`，需 `bell` 启动；`bloom` → C 的 `bloom—exit` |
| 双源汇流 | `dew/bell` → B 的 `bell—relay`；`bloom` → C 的 `bloom—relay`；均需 `bell` 启动 |
| 远端折返 | `dew` → A 的 `dew—relay`，需 `dew` 启动；`bell/bloom` → C 的 `bloom—hub`，需 `bell` 启动 |
| 分源架桥 | `dew/bell` → B 的 `bell—relay`，需 `dew` 启动；`bloom` → C 的 `bloom—exit` |

通向出口的临时桥仍须满足三机关全部完成。影桥的额外前置确保永久返程已接通；到期撤销新进入资格，保留已踏上段的 `committed` 几何与支撑直到落地。过期后不能把玩家留在只有已消失影桥能返回的节点。

棱镜仅在归响台或锚台使用，必须有蓄能且当前层有已完全供能、未启动的机关，每次消耗 1。它不能绕过双源前置、W 条件或出口的全机关要求。新方向首次冒险或完整花匣成功产生一次蓄能机会，上限随等级为 1 / 2 / 3。留影、棱镜和缓落壳跨庭并存、同类升阶，每庭次数重置，生命不重置。

## 三种可选花匣挑战

花匣基座始终稳定，入口与返回桥在逻辑 B 层。每庭只能开匣一次，不论成功或失败；开匣后收起桥，不能移动、存入或用主动能力跳过挑战，W 切换继续可用。

| `variant` | 波次与危险 | 奖励 |
| --- | --- | --- |
| `single` 单层回流 | 一波 `2.4s`，危险为开匣层；另外两个实体层均安全 | 4 |
| `chase` 追层双涌 | 两波，各 `2.4s`；首波危险为开匣层，第二波危险为首波结束时玩家成功躲入的层 | 6 |
| `lock` 双层封锁 | 一波 `2.6s`，封锁两个层；唯一安全层由种子从逻辑 A/C 中选择 | 5 |

`wave` 提供 `dangerLayers`、`safeLayers`、`step`、`steps`、`variant`、`remaining`、`duration`。兼容字段 `layer` 只是首个危险层，视图不能用它替代完整危险集合。安全要求在 `safeLayers` 中且实体切片足以支撑；层间隙永远不算安全。

第一波成功只发 `dodge` 并立刻为下一波重新预告，不给部分奖励。全部成功才发一次 `reward` 加 `evade`，后者只提供释放反馈，不能重复发奖或播放第二段成功旋律。失败消费本庭机会并承担普通损失。结束后恢复入口桥，从 B 层安全返回。重开或换庭取消旧波；没有模型更新时倒计时不推进。

## 收益与失败不变量

- 新方向首次稳行得 1，首次冒险得 3。已领取方向不能再转换成风险奖励；已存来源不能重复提款。
- 普通失败丢未存回响并消耗一枚回程结，保留已存成绩、已启动机关和已发出的真实供能。未存收益丢失后可重新挣回，但同一来源不重复提供棱镜蓄能。
- 缓落壳每阶每庭保护一次回响和生命；失败仍清除连响、脉冲和影子，不能恢复已消费花匣。
- 待抵达供能是已提交的世界行为，普通失稳不能取消；重开或换庭取消旧房间任务。庆祝队列可以取消，不能据此回滚真实机关状态。

## 呈现与验证边界

场景读取模型节点、边、供能接收槽和危险集合，不另算开锁规则。风险成功有聚光、花瓣/冠环、奖励回收，并沿已打开的相邻桥传播视觉回响；这种庆祝不额外开锁或造奖。新危险出现时清除延迟庆祝，危险层始终可读。声音以模型剩余时间驱动预警；换阶段替换旧危险节奏，部分躲避与完整成功分开。分级成功扩展音域与收束层次，不上调主增益；效果、粒子和声音保持数量上限并支持减少动态效果。

`npm test` 当前共 58 项，包含 100 个种子 × 三庭的无遗物能力通关、各模板/层排列、投影间距、双源必要性、影桥到期、花匣阶段/失败、收益身份与音画取消规则。独立状态遍历可补充检查所有可达分支；自动化不能证明玩家理解度、主观听感或趣味性。浏览器操作结果由本轮独立验证记录报告，历史截图不充当本轮证据。
